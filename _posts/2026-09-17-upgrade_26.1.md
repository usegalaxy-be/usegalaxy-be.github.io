---
title: Upgrade to Galaxy version 26.1
tags: [upgrade]
---

UseGalaxy.be has been upgraded to 26.1, which introduces some nifty new features:
- Galaxy Notebooks: histories can be turned into notebooks combining narrative, datasets, visualizations, and AI-assisted writing.
- Bulk dataset storage migration, which makes it easier to manage storage at scale.
- Favorite and recent tools panel for faster access to the tools you use the most.
- The history-to-workflow extraction interface has been rebuilt, making it more intuitive.
- And much more, which can be found in the official post of The Galaxy Project on [release v26.1](https://docs.galaxyproject.org/en/master/releases/26.1_announce_user.html).

Please report any (new) issues you are experiencing to us via: 'datacore.galaxy (at) vib.be'. The UseGalaxy.be team thanks you!
